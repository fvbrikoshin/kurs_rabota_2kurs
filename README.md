Данный скрипт на языке R предназначен для обработки и визуализации данных по лексемам со значением 'гусеница в нахско-дагестанских языках, и не нахско-даегстанских языках, ареалы которых близки к ареалам нахско-дагестанских языков.
Программа строит три карты с клеточной структурой, которые отображают географическое распределение данных лексем по определенным признакам.

## Требования
Следующие библиотеки R должны быть установлены, чтобы обеспечить правильную работу скрипта:
1. **tidyverse** (для манипуляции данными, построением графиков)
2. **readxl** (для чтения таблицы в формате .xlsx)
3. **RCaucTile** (пакет, необходимый для генерации карт с клетчатой структурой)

## Входные данные
Данный скрипт работает с файлом в формате .xlsx, который по умолчанию называется "КАВКАЗ_ГУСЕНИЦА_version23.xlsx". В данном файле должны содержаться следующие столбцы: **language** (название языка), **meaning_translation** (компоненты лексемы), **value2 (snake/worm)** (если ли элемент 'червь'/'змея') в лексеме или нет, **value3 (god)** (есть ли элемент 'Аллах' или нет).

## Запуск скрипта
1. Поместите файл в формате .xlsx в рабочую директорию со скриптом R.
2. Откройте скрипт в компиляторе.
3. Убедитесь, что установлены нужные пакеты.
4. Запустите скрипт.

## Выходные данные
После завершения работы скрипта в рабочей директории будут созданы три изображения-карты:
1. **value1.png** - карта распределения производных/непроизводных лексем;
2. **value2.png** - карта распределения компонента 'червь'/'змея';
3. **value3.png** - карта распределения компонентв 'Аллах'.
